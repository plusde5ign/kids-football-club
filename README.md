# Academia de Fotbal

Pagină de prezentare în limba română pentru grupele 2012-2021.

## Personalizare înainte de lansare

Înlocuiți identitatea temporară, programul orientativ, locația, imaginile ilustrative și exemplele de mărturii. Conectați butoanele de probă la metoda reală de programare a clubului. Pagina nu colectează date personale și nu înregistrează rezervări.

## Dezvoltare

React, Vinext, TypeScript. Instalare cu pnpm. Comenzi: pnpm dev, pnpm build.

Fonturi: Barlow Condensed și Manrope, Google Fonts. Imaginile sunt ilustrative, generate pentru acest concept.
